# Classification-des-emotions avec XLNet

Ce projet contient un code complet pour classifier des émotions dans du texte (colère, peur, joie, tristesse) en utilisant le modèle pré-entraîné XLNet.  

Le dossier inclut :  

Préparation et nettoyage des données CSV (train, val, test)  
Analyse exploratoire et rééquilibrage des classes  
Encodage des labels et création des ensembles d'entraînement, validation et test  
Tokenisation avec le tokenizer XLNet  
Fine-tuning du modèle pour la classification  
Évaluation et déploiement via un pipeline Hugging Face  

Le code est prêt à être exécuté dans Google Colab ou localement avec GPU.
